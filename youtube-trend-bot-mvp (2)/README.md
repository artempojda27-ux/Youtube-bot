# YT Trend Scout — MVP

Внутренний инструмент: сканирует YouTube США по ключевым словам ниши,
ранжирует по реальной скорости роста просмотров (не по абсолютным цифрам),
и генерирует сценарий лонгформа + нарезку на Shorts под формат
"AI-аватар с лицом".

## Что работает

- **YouTube Data API v3** (`lib/youtubeApi.ts`) — официальный, бесплатный,
  без скрейпинга. Нужен только ключ из Google Cloud Console.
- **Скоринг** (`lib/scoring.ts`) — просмотры/день (velocity) важнее
  абсолютных просмотров: свежее растущее видео сильнее старого с
  накопленным охватом. Плюс engagement rate.
- **Генерация сценария** (`lib/claude.ts`) — полный сценарий с
  таймкодами + 3-5 кусков под Shorts с отдельными хуками на каждый.
- **AI-disclosure напоминание** — встроено в каждый сценарий: с 2026
  YouTube требует отмечать реалистичный AI-аватар с лицом/голосом в
  поле "AI Use" при загрузке. Финансовые темы получают более заметную
  плашку прямо на плеере — помечается отдельно.

## Что нужно доделать

1. **Квота YouTube API** — базовая 10,000 юнитов/день. `search.list`
   стоит 100 юнитов за вызов, так что это ~100 поисков/день на старте.
   Хватает за глаза для ручного использования, но если начнёшь
   автоматизировать регулярное сканирование — подай заявку на
   увеличение квоты в Google Cloud Console заранее.
2. **Сохранение истории** — сейчас идеи и сценарии живут только в
   состоянии фронта. Для отслеживания "что уже снял, что в очереди"
   нужна база — можно переиспользовать тот же Supabase, что и в
   ai-dropship-mvp, отдельной таблицей `youtube_ideas`.
3. **channels.list** — можно добавить проверку подписчиков канала-
   источника: маленький канал с высокой скоростью роста — более
   доступная для повторения ниша, чем то же самое у канала-миллионника.
4. **HeyGen/Creatify** — рендер самого видео по сценарию не подключён
   в этом MVP; используй `lib/video.ts` из ai-dropship-mvp как основу,
   логика подключения идентична (BYOK, тот же паттерн вызова).

## Порядок запуска

```bash
npm install
cp .env.example .env.local   # вписать YOUTUBE_API_KEY и ANTHROPIC_API_KEY
npm run dev
```

## Порядок работ

1. Получить ключ YouTube Data API v3 (5 минут, мгновенно активен —
   в отличие от Meta, тут нет верификации и ожидания)
2. Прогнать 3-5 ключевых слов из своей ниши, посмотреть на реальные
   результаты скоринга — сверить с собственным чутьём, совпадает ли
3. Сгенерировать первый сценарий, проверить, что тон и структура
   подходят для реальной записи с аватаром
4. Только потом подключать рендер видео — сценарий дешевле проверить
   глазами, чем генерировать зря
